# Genre identity with shared gameplay invariants
Shared invariants: note shape/direction meaning, hitbox geometry, lane dimensions, timing, collision contracts,
minimum note/background contrast, scale/origin conventions, export rules.
Genre-specific variables: palette, architecture, materials, emission, atmosphere, beat-reactive motion, transitions.
Example directions:
- Industrial techno: rigid machinery, dark metal, restrained amber/red accents.
- Synthwave: horizon lines, retro-futurist forms, cyan/magenta/purple.
- Organic/experimental: crystalline or fluid forms, layered translucency, teal/violet.
Treat these as examples, not requirements. Never change the visual meaning of gameplay cues.
